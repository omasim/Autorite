# Site Information Architecture v0.1
## autorite.org
- Home — program status and current cycle
- Questions — Q0–Q5 and descendants
- Current Knowledge — current scoped claims and conflicts
- Research — active/closed RPs
- Reflections — interpretive essays clearly typed
- Archive — Autorite 1.x and superseded publications
- Methods — Constitution, contracts, formal capability policy
- About — program identity, governance and contribution/review

## autorite.net
- Research Network / Lab home
- Live research status
- GitHub / code / datasets
- Open reviews and contribution guide
- Releases and reproducibility bundles
- Links to canonical knowledge pages on autorite.org

## Canonical URL rule
Knowledge objects have canonical URLs on autorite.org. autorite.net does not duplicate full claim/question/publication content.

## Public epistemic UX
Each current claim should expose: type, scope, status, evidence, limitations, version, “does not imply”, and “what would change our view”.
