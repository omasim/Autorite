# Autorite 2.0 — GitHub, Website and Domain Publishing Plan v0.2
## Locked architecture
**One canonical research source; two separate websites from launch.**

GitHub is the canonical living research record.

### autorite.org — Knowledge / Publication
Public, durable, editorial projection: Questions, Current Knowledge, Research summaries, Reflections, Archive, Methods, Publications, About.

### autorite.net — Laboratory / Network
Live operational research projection: current Cycle, active RPs, experiments, results, deviations, blockers, reviews/challenges, DAM X archaeology, code/data, releases, contribution.

The sites are separate applications and deployments. They must not become separate epistemic stores.

## Identity
Both use the selected **Horizon** mark: open circular arc + horizon line. It represents open-ended inquiry.

## Cycle Ring
Both sites use the same canonical Cycle Ring:
- Cycle number in the center;
- circular ring filled by completion of declared research obligations;
- never computed from elapsed time;
- 100% ring = Cycle CLOSED;
- closed Cycle remains visible historically.

`Horizon Logo = Open Inquiry`  
`Cycle Ring = Finite Research Commitment`

## Publication rule
Autorite itself never reaches a terminal CLOSED state. Individual Cycles close and every closed Cycle publishes results, Synthesis Review, open questions, knowledge snapshot and transition record.

## GitHub
`main` = living Autorite. Immutable anchors: `baseline-v0.1`, `cycle-NN-open`, checkpoints, `cycle-NN-close`.

Research change → typed result/decision → PR → validation → canonical merge → independent `.org` and `.net` projections.
