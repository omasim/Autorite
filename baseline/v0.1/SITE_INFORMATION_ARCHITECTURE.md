# Site Information Architecture v0.2
## Shared
Two separate sites, one canonical Git research record. Shared Horizon identity and Cycle Ring semantics.

## autorite.org — Knowledge / Publication
Home; Questions; Current Knowledge; Research; Reflections; Archive; Methods; Publications; About; Changes.

Home prominently shows the current Cycle Ring in an editorial form: Cycle number centered, obligation-based progress ring, Cycle title/status. It links to the live laboratory on autorite.net.

## autorite.net — Laboratory / Network
Lab Dashboard; Current Cycle; Research Packages; Experiments; Results; Reviews/Challenges; Legacy/DAM X; Code; Data; Releases; Contribute; Method Status.

Dashboard prominently shows the same Cycle Ring, with operational breakdown of RP/review/synthesis/publication obligations.

## Canonical URL split
autorite.org is authoritative for public knowledge/claims/publications/reflections. autorite.net is authoritative for live operational research pages, runs and reproducibility views. Shared IDs connect the projections; avoid duplicate full text.

## Cycle archive
Closed Cycles retain a fully completed ring and immutable close snapshot. The program itself remains open-ended.
